 Supply Chain KPI Identification and Analysis

## Project Overview
This project analyzes five key supply chain performance indicators using a hypothetical dataset of 50 orders.

## KPIs Covered
- On-Time Delivery Rate
- Inventory Turnover
- Order Accuracy Rate
- Order Fill Rate
- Order Cycle Time
- Perfect Order Rate (summary metric)

## Files
- `Supply_Chain_KPI_Analysis.xlsx` — dataset, KPI summary, impact analysis and chart
- `Supply_Chain_KPI_Final_Report.docx` — detailed documentation
- `README.md` — project overview

## Tools
- Microsoft Excel
- Microsoft Word
- Data analysis and KPI calculations

## Important Note
The dataset is hypothetical and created for educational practice. It does not represent actual company performance.
