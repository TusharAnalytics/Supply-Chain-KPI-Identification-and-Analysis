This report presents a supply chain process map and analysis for the Week 3 task on process mapping and visualization. I studied seven typical stages of a supply chain: supplier sourcing, procurement, inbound logistics, warehouse and inventory management, order fulfilment, distribution and transportation, and customer and returns. Using Python and Matplotlib, I created a process map that shows the flow of goods, the flow of information back to planning, and the key performance indicators captured at each stage. The report explains each stage in detail and links it to specific data points, such as supplier lead time, purchase order cycle time, inventory turnover, order accuracy and on-time delivery. It also describes the analytical challenges at each stage, for example inconsistent supplier data, variable transit times, stockouts versus overstock, and unpredictable last-mile delivery. A dedicated section explains how data analytics can identify bottlenecks using methods like cycle-time analysis, control charts, ABC analysis, timestamp analysis and route-level performance analysis. The report also discusses challenges I faced, mainly limited public data availability and the need to simplify a real network into one readable path. Finally, it suggests areas where further analysis could improve performance, including demand forecasting, supplier scorecards, inventory optimisation, route optimisation and predictive delay alerts. The report is based only on publicly known supply chain concepts and uses no private or company data.
